# Prior art register

Harness Lens records externally inspired techniques here so later contributors
can distinguish adopted design principles, independently written code, deferred
ideas, and rejected coupling.

- [Harness Evals](harness-evals.md): deterministic-first evaluation, explicit
  score methods, reliability/statistical techniques, and evidence boundaries.
- [Harness Score discovery](harness-score-discovery.md): deterministic traversal,
  safety fuses, root-bounded symlinks, and incomplete-scan semantics.
- [Error Lens](error-lens.md): standard diagnostic publication as the boundary
  between analysis and editor presentation.

Each note includes the research date, direct source links, licensing context,
and intentional differences.
