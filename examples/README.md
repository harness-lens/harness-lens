# Examples

Build/install the mixed Rust/Python package, then run:

```bash
harness-lens . --config examples/harness-lens.toml --json
python examples/python_scan.py .
```

Both commands return the same provider-neutral report generated by the Rust
core. The example configuration enables inventory, repetition, and conservative
incongruence plugins, and keeps the Harness Score integration disabled until a
transport is supplied.
